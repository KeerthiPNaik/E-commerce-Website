# E-commerce Website

A simple front-end e-commerce website built using **HTML**, **CSS**, and **JavaScript**.  
This project simulates a basic online store with product listings, categories, and a shopping cart interface.

## Features

- Responsive layout for desktop
- Product listing grid
- Product detail cards with images, prices, and descriptions
- Add to Cart functionality (basic front-end simulation)
- Shopping cart page or modal
- Navigation bar and footer
- Wishlist functionality (basic front-end simulation)

## How to run

1. Clone the repository:
   git clone https://github.com/KeerthiPNaik/E-commerce-Website.git
   
2. Navigate to the folder:
   cd E-commerce-Website

4. Open index.html in your browser.
